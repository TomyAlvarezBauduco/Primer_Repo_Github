Este es el primer repo que hago con la intencion de aprender

git init-> Inicializa git en el proyecto, si no lo utilizo se registran las carpetas de toda la pc

git remote add origin <enlace> Conecta remotamente a github

git remote -v sirve para ver la informacion de la carpeta en la que estamos 

git status-> Puedo ver que archivos estan registrados y cuales no

git add intro.txt->Registrame este archivo para eventualmente enviarlo al repo

git add .-> registra todo lo que este sin registrar (No recomedado de usar)

git commit -m "Nombre" para subir una version del archivo

git log-> registro de commits creados

git push-> envia los cambios al repo

entonces si escribo algo ahora en teoria debo cargarlo

registro->backup->envio 
add->commit->push

con git checkout + el id del commit puedo volver a una version anterior

Algunos comandos útiles:

q → salir/volver a la terminal
↑ / ↓ → moverte
Space → bajar una página
b → subir una página
/texto → buscar
n → siguiente resultado
